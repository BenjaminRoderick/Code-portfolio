# Data science projects

## Summary of this section

### New York City citizen complaints
- A small data science project using a dataset obtained from:

```
https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2010-to-Present/erm2-nwe9
```
- Using Jupyter notebooks and Unix command line interface (CLI) tools such as grep, leveraging Amazon Web Services (AWS) cloud computing services to deal with the very large dataset.

### North American Media coverage of president-elect Donald Trump
- A data science project undertaken with the goal of understanding how Donald Trump was covered by North American news outlets during his election campaign and after he won the 2024 presidential election.
- News articles were collected using newsapi via the requests Python module.
- The project took advantage of AWS cloud computing services to run Python scripts, Jupyter notebooks, and other Unix CLI-based tools.

### A simple database
- A simple project I started to keep track of all the books I've read.
- Using AWS to host the database in the cloud, I am able to access it from any machine.
- The database uses MariaDB.
