# Simple database

## About the project
- I started this project to keep track of all the books I've read; so many I was starting to lose track of where I was and which ones I've finished.
- My main goal was to create a way to keep track of what chapter I had last read on all of my current books, which books I've finished reading, and what books I want to read in the future.
- I also included information about themes and my personal reviews of certain books.

Since I can't really give open access to the database, I have provided a tutorial on how to set up a similar database on your own AWS EC2 or lightsail instance!
