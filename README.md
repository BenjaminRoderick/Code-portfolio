# Une petite introduction

J'ai sauvegardé sur ce site quelques projets de programmation sur lequels j'ai travaillé soit pour l'école, ou pour mes propres intérêts.

## Guide du site
- **SQL_and_databases** : Ce dossier contient un projet de système de gestion de base de données.
- **image_deblurring_denoising** : Un code pour reconstruire des images nettes à partir d'images floues.
- **data_science** : Ce dossier contient des projets de science de données.
    - **NYC_citizen_complaints** : On explore les plaintes des citoyens dans la ville de New York.
    - **trump_media_coverage** : Une étude de comment le futur président des É.-U., Donald Trump, a été couvert par les médias Nord-Américains durant l'élection de 2024, et après.
- **other** : Ce dossier contient des projets divers dans des langages de programmation tels que C, C#, Java, Python.

# About this repository

Here, I've collected several coding projects that I worked on either for school or for my own interests.

## Site map
- **SQL_and_databases**: A database management system for a social networking site.
- **image_deblurring_denoising**: A program for solving the "non-blind image deblurring" problem.
- **data_science**: This directory contains several data science projects.
    - **NYC_citizen_complaints**: An exploration of complaints from residents of New York City.
    - **trump_media_coverage**: A study of how president-elect Donald Trump was covered by North American news sources in the time before and after the 2024 presidential election.
- **other**: Various coding projects in languages such as C, C#, Java, Python
