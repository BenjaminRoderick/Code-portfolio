# Bot or Not: Detection of Social Media Bots on X (formerly Twitter)

[project report](https://github.com/BenjaminRoderick/Code-portfolio/blob/main/bot_or_not/bot_or_not.pdf)

## How to run the code

### Social Media Bot
1. Set the environment variable **ENV_API_TOKEN** to the value of your OpenAI API token (this is required for the code to function as intended)
2. > python ./docker/Bot/test_bot.py

### Bot Detector
Simply run:

  > python ./src/train_filtered_dataset.py
